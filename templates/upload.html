WORKS ONLY WITH 9th EDITION ROSTERS!

How to use this tool

  • 1) Select your battle scribe *.ros or *.rosz file
  • 2) Select options you need
  • 3) Press button and enjoy!

Options

  • Show Units ID in Phase Table
    • Stratagem by Phase table will show, which stratagems can be used with which units. (For Example: VENGEFUL SKIES [1] [2])
    Stratagem by Unit table will have ID for each unit. (For Example: [1] Master of Possession, [2] Chaos Lord in Terminator Armour)
  • Show Phases in Units Table
    • Stratagem by Unit table will have phase name for each stratagem ("Cp" for Command phase, "ESp" for Enemy Shooting phase etc). (For Example: VESSELS FOR THE NEVERBORN [EFp] [Fp])
  • Show Stratagems without Unit specific requirements
    • Some Stratagems do not require specific Units to be used. If this option is selected, they will be added to Stratagem by Phase table.
  • Show Core Stratagems
    • Core Stratagems are added to Stratagem by Phase table.
  • Don't show Army of Renown Stratagems
    • If you have Army of Renown, specific Stratagems won't be added to Stratagem list. (For Example: [Speed Freeks Speed Mob] for Orks or [Vanguard Spearhead] for Space Marines)
  • Don't show "Before Battle" Stratagems
    • Stratagems from Before Battle phase are not shown. (For Example: Warlord Trait/Relic etc.)
